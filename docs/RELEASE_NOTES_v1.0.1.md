Capture v1.0.1 小版本更新：热键可直接按键录入，开机自启动只驻留托盘。

热键捕获：设置页每行新增「更改」按钮，点击后直接按组合键即可录入并自动应用保存；Esc 可取消。

开机自启动：勾选后开机仅托盘驻留、不弹主窗口；旧版本已写入的自启动项会自动补上该行为。

配置：首次启动自动建出完整默认配置；配置固定在 exe 同级 `config/`，拷走即带走；
exe 在不可写位置（如 `C:\Program Files`）时自动改放 `%APPDATA%\Capture`。

兼容：发布产物静态链接运行库，干净机器下载即用；低于 Windows 10 1803 时启动即明确提示。

需 Windows 10 1803 及以上。exe 未做代码签名。
